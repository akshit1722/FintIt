# FindIt Demo Asset Pack

This package contains sample visual assets for the FindIt – Lost & Found Campus Platform.

## Folder structure

- assets/images/banners/
  - campus-hero.jpg
- assets/images/items/
  - backpack, water bottle, earbuds, student ID, books, wallet, keys, glasses,
    calculator, headphones, smartphone, notebook, pen, hoodie, cap and umbrella
- assets/images/illustrations/
  - search, checklist, handshake, grid, gradient, bokeh, wave, circles,
    dots, line pattern and location graphics
- assets/icons/
  - FindIt logo and simple navigation icon images

## How to use

1. Extract this ZIP.
2. Copy the `assets` folder into the root of your FindIt project.
3. Reference images with paths such as:
   `assets/images/items/backpack.jpg`
   `assets/images/banners/campus-hero.jpg`
   `assets/icons/findit-logo.png`

If your HTML file is inside a subfolder, adjust the relative path accordingly.

## Important

These are illustrative demo assets generated for prototyping and layout testing.
The campus building is not a verified photograph of your college. Item images,
logo artwork and visual patterns are placeholders. Replace them with authentic
campus photographs or approved branding before public launch or final submission.

No real student identity card or personal data is shown.
